ссылочные типы - срезы, указатели, отображения, каналы, функции (нулевое значение - nil)

указатель - это местоположение в памяти, где хранится значение.

строка - последовальность байтов 
    len - возвращает количество байтов а не символов!
    s[i] - i-тый байт

строковой литерал - последовательность байтов,заключенная в двойные кавычки
руна - код символа Unicode 

strconv.Itoa - Integer to ASCII

массив - последовательность фиксированной длины из нуля или более элементов определенного типа.

размер массива является частью его типа, те типы [3]int и [4]int различны

срез - последовательность переменной длины, все элементы которой имеют один и тотже тип.
тип среза - []T - как тип массива, без указания размера.

срез состоит из трех элементов: 
  - указателя, 
  - длины
  - емкости

за исключением сравнения со значением nil нулевой срез ведет себя как любой другой срез нулевой длины; например, вызов reverse(nil) является совершенно безопасным

make - создает срез с определенным типом элеметов, длиной и емкостью. Емкость мб опущена, в таком случае емкость принимается равной длине:
make([]T, len)
make([]T, len, cap) // то же, что и make([]T, cap)[:len]

За кулисами функция make создает неименованную переменную массива и возвращает его срез.

append - добавляет элементы в срез

вариадическая функция - функция с переменным числом аргументов

отображение - ссылка на хеш-таблицу

элементы отображения не являются переменными, и мы не можем получить их адреса:
порядок итераци по отображению не определен

сохранение значений в нулевом отображении приводит к аварийной ситуации

структура - агрегированный тип данных
порядок полей имеет значение - разный порядок разные типы
поле структуры экспортируется если его имя начинается с прописной буквы.

агрегатное значение не может содержать само себя.

рекурсивные структуры данных - связанные списки и деревья

структура без полей - пустая структура struct{}

Композиция является центральным моментом объектно-ориентированного программирования в Go

маршалинг - преобразование структуры данных GO в JSON

действие - строка или файл, содержащая один или несколько фрагентов в фигурных скобках {{...}}

golang.org/x/... - новые разные пакеты

Сборщик мусора Go освобождает неиспользуемую память, но не считайте, что он будет освобождать неиспользуемые ресурсы операционной системы, такие как открытые файлы и сетевые подключения. Они должны быть закрыты явным образом.

Функция-значение - это когда присваиваешь обычную именованную функцию переменнойю
Анонимная функция - это функция без имени, определенная прямо на месте.

Анонимные функции могут замыкать переменные из окружающего контекста (замыкания). Обычные функции - нет.

Замыкание - это анонимная функция, которая использует переменные из внешней области.

Детерминированный - знаит, что результат всегда одинаковый при одинаковых входных данных.

Вариативная функция - это функция, которая может быть вызвана с разным количеством аргументов.

Паника - ошибка выполнения.
Паника может вызываться непосредственно.

Объект - значение или переменная, которая имеет методы.
Метод - функция, связанная с определенным типом.

Go - разрешает связывать методы с любым типом, что отличает его от многих других ооп языков программирования.

Go не умеет итерировать по битам

Инкапсуляция имеет три преимушества:
  1 меньше изучать про объект
  2 устраняет зависимость клиентов от сущностей которые могут изменяться 
  3 не позволяет клиентам произвольным образом менять значения переменных объекта

Интерфейс является абстрактным типом

Это может казаться бесполезным, но на самом деле тип interface{}, который называется Пустым Интерфейсом, является необходимым. Поскольку тип пустого интерфейса не накладывает никаких требований на типы, которые ему соответствуют, пустому интерфейсу можно присвоить любое значение.
